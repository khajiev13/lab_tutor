Job grouping now uses AI.

Deployed and verified

What I corrected

The previous job-grouping change used regular expressions to remove seniority words and a small role-alias table. That was a rule-based implementation, and I should have described it clearly.

Those rules are removed. The model now compares titles and complete job descriptions to decide which postings describe the same role.

  1. AI groups equivalent roles across languages, wording and seniority.
  2. Code checks that every posting ID appears exactly once.
  3. Original descriptions, job URLs and posting records stay attached to their groups.

If the model fails, returns invalid groups, or exceeds the input budget, postings stay separate. There is no regex or alias-based fallback. This correction changes job-role grouping; skill semantic clustering already runs as a separate AI step.
