# Frontend restoration deadline — 2026-10-14

## Scope and behavior

- Changed `frontend/src/features/market-demand/hooks/useAgentStream.ts`, its hook test, and the existing `MarketDemand.test.tsx` page test only.
- `reconcile()` previously awaited all four snapshot reads without a deadline. An unresolved history, state, review, or execution-status request therefore left initial `isLoadingHistory` true indefinitely.
- One 30-second deadline now covers the complete reconciliation, including the optional second consistency read. The deadline independently rejects the wait and aborts all four request signals; an abort-ignoring dependency cannot retain the loading state.
- A timed-out current request reports `Conversation restoration timed out. Retry restoration to try again.`, clears the loading indicator, and keeps ordinary mutations blocked. The existing page exposes Retry restoration. Retry starts fresh requests and can successfully restore.
- Course/request/generation ownership remains separate from signal cancellation so the current timeout can publish its error while old requests cannot publish data, errors, or loading state. Existing revision floors, transcript retention, source settings, reset behavior, and stream duration remain unchanged.
- No global API timeout, automatic retry, backend/API/schema changes, commits, push, or deployment.
